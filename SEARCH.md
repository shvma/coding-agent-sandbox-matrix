# Разведка: песочницы кодовых агентов

Обновление 2026-10-29: появились [runtime-прогоны](results/2026-10-29/README.md) и [рекомендация](RECOMMENDATION.md). Ниже сохранены решения разведки; проверенными считаются только явно измеренные сценарии.

Два варианта изоляции кодового агента из постановки.

Вариант OpenShell разведан отдельно: `openshell/SEARCH.md` (+ сырьё в `openshell/results/`).
Вариант «встроенная песочница Claude Code» разведан 2026-10-15 по первоисточнику
`https://code.claude.com/docs/en/sandboxing` и `.../managed-settings`. Ниже только решения;
подробности механизмов и границ — по ссылке на первоисточник, не пересказываю.

## Встроенная песочница Claude Code — решения

- **Берём как есть на Mac.** Изоляция команд оболочки на примитивах macOS (Seatbelt), ставить нечего, Docker и VM не нужны. Включается `/sandbox` или ключом `sandbox.enabled` в настройках.
- **Архитектурное отличие от OpenShell.** Здесь граница — локальная песочница на том же ядре, что и хост. У OpenShell решение принимает внешний supervisor, а на Mac workload ещё и в отдельной Linux-VM. Это и есть главный пункт сравнения для таблицы.
- **Настраиваем обязательно, иначе защита дырявая по умолчанию.** Политика для всех — managed settings (`/Library/Application Support/ClaudeCode/managed-settings.json`): запуск без песочницы запрещён, escape-hatch выключен; плюс явная защита каталогов с учётными данными и список разрешённых доменов. Конкретные ключи — в первоисточнике.
- **Границы защиты документированы.** У страницы есть раздел «Limitations»: авторы прямо перечисляют, где песочница не является жёсткой границей. Это материал для страницы «что сказать команде платформы и безопасности», и его берём цитатами из первоисточника, не из пересказа.

## Что это меняет в проекте

Постановка требует сравнить два варианта и свести матрицу «режим × контроль × атака». Разведка подтверждает, что сравнение осмысленно: варианты различаются архитектурно, не косметически. Один набор из пяти классов атак гоняется против обоих. Версии фиксируем: Claude Code по `claude --version`, OpenShell по релизу (см. `openshell/SEARCH.md`).

## Проверить руками (на стенде, не из документации)

1. Прочность изоляции на Apple Silicon документация числом не характеризует — меряем прогоном канареек.
2. Что из рабочего процесса агента уходит из-под песочницы в исключения — измерить, это дыра вне песочницы.
3. Поведение при попытке ослабить политику из файлов репозитория — проверить, что managed-режим это игнорирует.
