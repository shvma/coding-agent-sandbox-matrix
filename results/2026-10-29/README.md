# Первый воспроизводимый runtime-прогон

**Архив.** Новый прогон с исправленной методикой — [2026-10-30](../2026-10-30/README.md). Этот снапшот записан схемой 1; `scripts/check.py` его больше не пересчитывает.

Дата: 2026-10-29. Хост: macOS 26.6.2, Apple Silicon; Docker Engine 29.4.2 (так записано в `openshell/raw.json`; прежняя версия этого файла ошибочно называла это версией Docker Desktop, а её стенд в тот день не записал), Linux VM. Это не один прогон одной командой. По артефактам: шлюз OpenShell в `lab.json` и `openshell/raw.json` запущены около 18:42Z, а `srt/raw.json` начат в 21:25:48Z. SRT перезапускали отдельно и положили результат в тот же каталог; вывод исходной команды и её код завершения не сохранены. Прежняя фраза «выполнена команда `npm run matrix -- --with-openshell --output results/2026-10-29`, код завершения 0» этими артефактами не подтверждается.

| Вариант | Версия | Профили | Наблюдения | Источники |
|---|---|---|---|---|
| Standalone SRT, Seatbelt | 0.0.81 | control, baseline, hardened, offline | 7 × 4 = 28, ожидания совпали | [матрица](srt/matrix.md), [сырые данные](srt/raw.json) |
| OpenShell, Docker driver, Landlock hard_requirement | 0.1.6 | control, baseline, hardened | 7 × 3 = 21, ожидания совпали | [матрица](openshell/matrix.md), [сырые данные](openshell/raw.json) |

Это 49 наблюдений, включая положительные контроли, а не 49 разных атак. Успешная передача маркера по разрешённому каналу — ожидаемый остаточный риск, а не сработавшая защита.

[Журнал лаборатории](lab.json) содержит проверенный SHA256 CLI, запуск gateway, его конфигурацию, stdout/stderr и удаление gateway. OpenShell raw содержит digest образов, сборку fixture, реально переданные политики, effective policy, команды workload и очистку. SRT raw содержит конфигурации, версии Node/Python/SRT и SHA256 lockfile. В обоих сохранены отпечатки payload/runner и наблюдения приёмников. Секреты и системные managed settings пользователя не использовались. Канарейка в этом снапшоте передавалась пробе в командной строке, поэтому строка «Передача маркера» показывает отправку известного пробе значения, а не украденного секрета. Абсолютные пути хоста в `lab.json`, `srt/raw.json` и `openshell/raw.json` заменены после прогона: каталог репозитория — на `$REPO`, домашний каталог — на `$HOME`. Другого содержимого замена не меняла.

В baseline OpenShell доступ к каталогу канарейки разрешён явно, env передаётся намеренно. В hardened каталог убран из read-only путей, env не передаётся. Это проверяет эффект выбранной конфигурации; сравнивать такую baseline с настройками продукта по умолчанию нельзя. Контроль запускается тем же UID 1000 в том же образе, каталоги допускают запись по обычным Unix permissions: отказ записи в workload нельзя объяснить только правами владельца файла.

HTTP и прямой TCP проверяют запрещённый порт того же приёмника; отдельный запрещённый домен не испытывался. Получение HTTP-маркера подтверждено приёмником. Маркер передаётся в URL обычного GET, TLS и содержимое L7-политик этим тестом не проверяются. Канарейка заранее известна тесту: отсутствие переменной означает проверку удаления/непередачи env, а не доказательство невыводимости её значения из всех каналов процесса.

Без network rules OpenShell в диагностическом запуске давал ошибку DNS, которую стенд не засчитывает как отказ политики. Поэтому профиль offline в финальной серии OpenShell не заявлен проверенным. В SRT offline измерен: полезная запись работает, оба HTTP-запроса получают явный отказ.

Не проверены: Claude Code и managed precedence, реальная IDE, встроенные инструменты агента, prompt injection, продуктивность разработчика, providers с реальными API, другие compute drivers и CI-инфраструктура команды. Вывод для выбора инструмента — [рекомендация к пилоту](../../RECOMMENDATION.md).

Матрицы пересчитываются из raw через `python3 scripts/run.py --render` с путём к соответствующему JSON. Проверка репозитория сверяет сохранённые таблицы с этим пересчётом.
